What you’re watching

  1. One goal goes to the planner.

    It creates a schedule using your topics and time budget.

  2. The planner delegates through A2A.

    It discovers each specialist’s Agent Card and exchanges real messages over localhost HTTP.

  3. The specialists return their own results.

    The resource finder selects curated materials. The checker independently validates the plan.

  4. Feedback changes the plan.

    Enable the repair example to see the checker catch an intentionally overbooked day and approve a corrected version.

Scripted mode makes no model calls. Gemini mode uses your configured key. Playback controls change how events are presented, not how the agents execute.
